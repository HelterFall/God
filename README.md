# God — Unity Game Folder Analyzer

Android-приложение для анализа папки Windows Unity-игры напрямую через Android Storage Access Framework (SAF).

## Главное
Исходная папка игры не копируется в приложение. Пользователь выбирает каталог через системный picker. Приложение рекурсивно перечисляет файлы через SAF и потоково читает только нужные заголовки/метаданные. Игровые EXE/DLL не запускаются и не модифицируются.

## MVP
- Рекурсивное дерево папок и файлов.
- Эвристическое определение Mono / IL2CPP.
- Поиск Managed, MonoBleedingEdge, GameAssembly.dll, il2cpp_data/Metadata/global-metadata.dat, UnityPlayer.dll и Assembly-CSharp.dll.
- Поиск строки версии Unity в globalgamemanagers.
- Определение PE machine (x86/x64/ARM64) по заголовкам.
- Экспорт Markdown-отчёта.

## Сборка
Открыть в Android Studio с JDK 17, Android SDK 35, выполнить Gradle Sync и собрать app.

## Использование
1. Установить приложение.
2. Выбрать корневую папку игры через системный picker.
3. Нажать «Анализировать папку».
4. Экспортировать отчёт в выбранное пользователем место.

## Ограничения
Это анализатор, а не Unity runtime. Он не копирует папку игры, не запускает EXE/DLL и пока не декомпилирует игровые сборки и не анализирует все форматы Unity assets. SAF-провайдер может ограничивать доступ к отдельным каталогам. Сканирование ограничено 100 000 записей и глубиной 40.
